# PIPE-SOGI -  Multi-Model Framework for Steel Price Forecasting and Financial Risk Assessment in the Oil & Gas Industry

## 📖 About the Project
This repository contains a **P**ipeline for **I**ndustrial **P**rice **E**stimation – **S**teel to **O**&**G** **I**ndustry (**PIPE-SOGI**), a forecasting framework designed to benchmark statistical and Deep Learning models for steel price prediction and financial risk assessment in the Oil & Gas industry.

The project is intentionally structured using Jupyter Notebooks, this way to offer a simplified and more accessible framework for non-IT professionals, especially those in project management and financial risk analysis. This notebook-based approach provides a more adaptable structure for this user profile, removing the need for a complex framework typically aimed at specialized computational researchers. The fundamental goal of this project is to bridge the gap between academic knowledge and industry practice. It aims to reduce costs and generate deeper insights into financial risk within the Oil and Gas sector through a joint effort between academia and industry.

## 🚀 Getting Started
These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

What you need to install the software and how to install them:

## ⚙️ Installation
A step-by-step guide that tells you how to get a development environment running.
Clone the repository:
git clone https://github.com/aguinaldoflor/PIPE_SOGI.git
Navigate to the project directory:

Create and activate a virtual environment (recommended):

python -m venv venv

source `venv/bin/activate`  # On Windows, use `venv\Scripts\activate`

Install the dependencies:

pip install -r requirements.txt

## 💻 How to Use
To run the analysis notebooks, start Jupyter Notebook or JupyterLab from your terminal:

VSCode

or

jupyter notebook

or

jupyter lab

Then, navigate through the notebooks in the order that makes the most sense for your analysis, likely starting with PIPESOGI_000_Data Analysis.ipynb for a general overview.

## 🗂️ Project Structure

The repository is organized as follows:

/dataset: Contains the raw datasets used in the analyses.

/output: Stores intermediate outputs generated by the notebooks.

/result: Contains the final results, such as visualizations and analysis conclusions.

PIPESOGI_000_Data Analysis.ipynb: Initial notebook for exploratory data analysis.

PIPESOGI_001_CHI.ipynb: Notebook with data analysis and the framework specific to China.

PIPESOGI_002_USA.ipynb: Notebook with data analysis and the framework specific to the USA.

PIPESOGI_003_GER.ipynb: Notebook with data analysis  and the framework specific to Germany.

PIPESOGI_004_TUR.ipynb: Notebook with data analysis specific to Turkey.

requirements.txt: A file that lists all the Python libraries required to run the project.
