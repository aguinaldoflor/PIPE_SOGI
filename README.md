# PIPE-SOGI -  Multi-Model Framework for Steel Price Forecasting and Financial Risk Assessment in the Oil & Gas Industry

## 📖 About the Project
This repository contains a **P**ipeline for **I**ndustrial **P**rice **E**stimation – **S**teel to **O**&**G** **I**ndustry (**PIPE-SOGI**), a forecasting framework designed to benchmark statistical and Deep Learning models for steel price prediction and financial risk assessment in the Oil & Gas industry.

The project is intentionally structured using Jupyter Notebooks, this way to offer a simplified and more accessible framework for non-IT professionals, especially those in project management and financial risk analysis. This notebook-based approach provides a more adaptable structure for this user profile, removing the need for a complex framework typically aimed at specialized computational researchers. The fundamental goal of this project is to bridge the gap between academic knowledge and industry practice. It aims to reduce costs and generate deeper insights into financial risk within the Oil and Gas sector through a joint effort between academia and industry.

## 🗂️ Project Structure

The repository is organized as follows:

/dataset: Raw input data used across the notebooks (e.g. `ptax.xlsx`, BRL/USD exchange rate).

/result: Outputs generated by the notebooks — hyperparameter caches, result/checkpoint spreadsheets and figures, one set per country (`chi`, `ger`, `tur`, `usa`) plus consolidated "all" comparisons.

**Country pipelines (probabilistic arm, `v2p`)**

pipe_sogi_v2p_chi.ipynb / pipe_sogi_v2p_ger.ipynb / pipe_sogi_v2p_tur.ipynb / pipe_sogi_v2p_usa.ipynb: Country-specific notebooks that run the statistical and Deep Learning forecasting pipeline (native quantile forecasting, 95% CI) for China, Germany, Turkey and the USA.

pipe_sogi_v2p_stats.ipynb: Cross-country statistical benchmarking of the forecasting models (ranking, Nemenyi/critical-difference tests, etc.).

pipe_sogi_v2p_var_fri.ipynb: Value-at-Risk (VaR) and Financial Risk Indicator (FRI) analysis built on top of the `v2p` pipeline outputs.

pipeline_v2p.py: Core module implementing the probabilistic forecasting pipeline (search space, quantile regression, ensembling, ranking) shared by the country notebooks.

var_v2p.py: VaR/Expected Shortfall layer for the probabilistic arm, including the native-quantile VaR method and backtesting (Kupiec, Christoffersen, traffic-light).

**Deep-Risk pipelines (`fz0`)**

pipe_sogi_fz0_risk.ipynb / pipe_sogi_fz0_risk_CHI.ipynb / pipe_sogi_fz0_risk_GER.ipynb / pipe_sogi_fz0_risk_TUR.ipynb / pipe_sogi_fz0_risk_USA.ipynb: Notebooks running the FZ0-Deep-Risk model (general and per-country).

fz0_deep_risk.py / fz0_deep_risk_PT.py: Deep-Risk model implementation (English and Portuguese versions).

**Other**

ptax.ipynb: Notebook for processing and analyzing the BRL/USD exchange rate (PTAX) data.

requirements.txt: A file that lists all the Python libraries required to run the project.

HYPERPARAMETERS_PIPE-SOGI.md: Documentation of the hyperparameter search spaces used by the models.

## 📄 Data Availability Statement

All source code, tuned hyperparameters, and the derived model outputs (out-of-sample forecasts, residuals, and native quantiles for every model and market) are openly available at GitHub, and are sufficient to reproduce the entire risk layer, backtests, and all reported statistical tests. The underlying steel price series are commercial index data licensed from third-party providers and cannot be redistributed; acquisition details are documented in the repository so that the forecasting stage can be reproduced by holders of an equivalent license.
